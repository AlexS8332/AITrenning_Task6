# Заметки по ходу — 06 Агент-справочник по животным

Черновик. Итоги — в карточке задания.

## 2026-09-07

- Пробы источников до кода: DeepSeek V4 поддерживает `tools`/`tool_calls`
  в OpenAI-совместимом формате; GBIF `species/match`, `parents`,
  `vernacularNames` и Википедия `list=search`, `prop=extracts` работают
  без ключей. Википедия требует осмысленный User-Agent.
- «полосатый манул» в поиске Википедии даёт «Московский зоопарк» и «Фауна
  Армении»: результаты есть, статьи нет. Проверять надо совпадение
  заголовка, а не факт наличия результатов.
- GBIF подтверждает `Petromus typicus` как EXACT: латынь под выдумкой
  настоящая, сверять надо связку русского названия с таксоном. Для этого
  есть `vernacularNames` с языком `rus`.
- Завершающий инструмент как контракт результата: `submit_card`,
  `submit_taxon`, `submit_section`, `report_not_found`. Программа проверяет
  аргументы по трекеру вызовов и возвращает модели отказ с причиной.
- Первый прогон «рысь»: перенаправление ведёт на статью о роде «Рыси», где
  нет разделов о питании и ареале. Добавлено правило: запрос без уточнения
  означает типовой вид, предпочитать «Обыкновенная рысь». Помогло.
- Специалист по среде обитания дважды получал отказ: называл раздел
  «Вступление» и «Рыси», которых трекер не знал. Разрешил пересказ по
  вступлению, если статья открывалась без раздела, и сравнение названий
  разделов по вхождению в обе стороны.
- Чат без инструментов на «малая выхухоль» отказывает, а потом выдаёт
  полную карточку пиренейской выхухоли «на случай, если вы имели в виду».
  Команда с инструментами на тот же запрос: три поиска, чтение статьи,
  сверка латыни и народных названий, отказ. 14 секунд и 0.14 цента.
- `go build -o` в PowerShell с `/dev/null` создаёт файл, помню по 05.
- Headless Edge `--dump-dom` для проверки страницы: карточка, журнал,
  счётчики на месте. Node в системе нет, JS иначе не проверить.

## 2026-09-08

- История схлопнута в один коммит: первый коммит шаблона тащил лишние
  файлы. Сообщение коммита через переменную PowerShell пришло одной
  строкой, переделал через here-string. Force-push с `--force-with-lease`.
- «Для соло и чат режимов в журнал ничего не пишется»: фильтр по агенту
  из прошлого прогона команды переживал новый прогон и прятал все записи
  одиночного агента. Фильтр теперь принадлежит прогону и сбрасывается при
  подключении к нему и при перерисовке чипов, если агентов меньше двух.
- Панель «Промпты»: событие `prompt` на старте каждого агента с системным
  промптом, первым сообщением и списком инструментов. В журнал ленты не
  идёт, интерфейс и отчёт показывают его отдельным разделом. Тест отчёта
  сломался на перезаписи: в тестовом промпте был текст запроса, по
  которому считались блоки прогонов.
- Разбор проекта по вопросам: агент здесь — всё, что реализует `Agent`,
  а не только вызов модели, координатор тоже агент. Инструмент — любая
  функция с именем, описанием и схемой; завершающие инструменты для модели
  неотличимы от обычных, разница на стороне программы. Память — история
  сообщений внутри одного `Run`, трекер вызовов, контекст, который
  координатор передаёт специалистам в первом сообщении, и кэш HTTP;
  долгой памяти между прогонами нет намеренно.
- Как ответ модели вызывает инструмент: модель ничего не вызывает, она
  возвращает `tool_calls` с именем и аргументами строкой, программа
  исполняет и кладёт ответ с ролью `tool` и тем же `tool_call_id`.
  Пропущенный ответ на один из нескольких вызовов ломает следующий запрос.
